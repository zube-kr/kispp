# KISPP 과학실

프놈펜한국국제학교(Korean International School of Phnom Penh) 중학교 과학 수업 홈페이지입니다.
2022 개정 교육과정 중1~중3 과학과 고1 과목(통합과학1·2, 과학탐구실험1·2)을 기준으로 구성합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 메인 화면 (왼쪽 학년·단원 사이드바 + 홈/단원 화면) |
| `data/board.js` | 메인 화면 게시판 데이터: 과학실 공지(`NOTICES`), 쉬어가는 과학 게임(`GAMES`) |
| `data/units.js` | 학년·단원 목록과 단원 설명, 영역 색상, 단원별 학습 자료 목록(`materials`) |
| `materials/` | 단원별 학습 자료 페이지 (예: `materials/g2-6/` 중2 Ⅵ. 동물과 에너지) |
| `js/config.js` | 공통 설정. 활동지 답안을 받을 구글 Apps Script 주소(`SUBMIT_URL`, 학년별 `SUBMIT_URLS`) |
| `apps-script/code.gs` | 활동지 답안을 학년 탭(중1·중2·중3·고1)에 저장하는 Apps Script (설치 방법은 파일 맨 위 설명) |
| `js/part-view.js` | 활동지 구간 보기 (`?part=concept` 등으로 열면 그 구간만 표시) |
| `js/ws-kit.js`, `js/ws-kit.css` | 시뮬레이션 워크시트 공통 채점·피드백·제출 (카드마다 [확인하기] 즉시 피드백, 사용법은 파일 맨 위 설명) |
| `layouts/` | 레이아웃 후보 샘플 (A~E)과 단원 화면 샘플(`layouts/unit-views/`), 참고용 |

## 주소 규칙

- `index.html#/g2` → 중학교 2학년 홈
- `index.html#/g2/3` → 중학교 2학년 3단원
- 고1 과목: `is1` 통합과학1, `is2` 통합과학2, `se1` 과학탐구실험1, `se2` 과학탐구실험2
  (예: `index.html#/is1/5` → 통합과학1의 5번째 단원 "지구시스템")

## 단원 수정하기

단원 이름이나 설명은 `data/units.js`만 고치면 메인 화면과 샘플에 함께 반영됩니다.

## 메인 화면 게시판

| 게시판 | 내용 채우는 곳 | 전체 보기(＋) |
|---|---|---|
| 과학실 공지 | `data/board.js`의 `NOTICES`에 공지 추가 (`pin: true`면 맨 위 고정) | `#/notice` |
| 실험 보고서 | 자동: 탐구실험(`lab`) 구간이 있는 우리 워크시트를 올린 날짜(`added`) 최신순으로 | `#/reports` |
| 쉬어가는 과학 게임 | `data/board.js`의 `GAMES`에 게임 추가 | `#/games` |

## 학습 자료 추가하기

1. 자료 페이지를 `materials/g학년-단원/` 폴더에 넣습니다.
2. `data/units.js`에서 해당 단원의 `materials` 목록에 항목을 추가합니다.
   - 다른 사이트 자료는 `external: true`를 붙이면 새 탭에서 열립니다.
   - `parts`: 자료 안의 구간 목록. `{ p: "concept", t: "실험 개요" }`처럼 적으면
     단원 화면에 색깔 칩으로 나오고, 누르면 그 구간만 열립니다.
     구간 종류: `concept` 개념정리 · `lab` 탐구실험 · `sim` 시뮬레이션 · `quiz` 형성평가
   - `added`: 올린 날짜(`"2026-10-16"`). 탐구실험이 있는 워크시트는 메인 화면 '실험 보고서'에 자동으로 나옵니다.
3. 활동지 페이지에서 각 `<section class="card">`에 `data-part="concept"`처럼 구간을 표시하고,
   `<script src="../../js/part-view.js"></script>`를 넣습니다. (표시가 없으면 카드 제목 배지로 짐작합니다.)
   제출 때 함께 채점되는 칸이 있는 구간은 `data-part="concept quiz"`처럼 두 가지를 적어
   형성평가만 열어도 제출할 수 있게 합니다.

## 단원 화면 구성

- 목록: 소단원 워크시트. 제목을 누르면 전체, 색깔 칩을 누르면 그 구간만(`?part=`) 열립니다.
- 위 네 버튼(개념정리·탐구실험·시뮬레이션·형성평가): 그 구간이 들어 있는 자료를 밝게 표시합니다.

## 활동지 답안 제출 연결하기

학생이 워크시트에서 [제출]을 누르면 구글 스프레드시트의 **학년 탭(중1·중2·중3·고1)**에 한 줄씩 쌓입니다.

| 제출 시각 | 워크시트 | 학년 | 반 | 번호 | 이름 | 점수 | 답안 | 교사 피드백 |
|---|---|---|---|---|---|---|---|---|

(학년마다 스프레드시트를 따로 만든 경우: `apps-script/code-g1.gs`(중1) · `code-g2.gs`(중2) · `code-g3.gs`(중3) ·
`code-h1.gs`(고1)를 각 학년 시트에 하나씩 붙여넣고, 모든 답안이 그 시트의 '답안' 탭에 쌓입니다.
아래 1~2를 학년 시트마다 하고, 3에서 주소 4개를 `SUBMIT_URLS`의 학년 칸에 각각 넣습니다.)

1. 스프레드시트에서 확장 프로그램 → Apps Script를 열고 `apps-script/code.gs` 내용을 붙여넣어 저장합니다.
2. 배포 → 새 배포 → 웹 앱(실행 사용자: 나, 액세스: 모든 사용자)으로 배포하고 주소를 복사합니다.
3. `js/config.js`에 주소를 넣습니다.
   - 스프레드시트 하나에 탭 4개: `SUBMIT_URL` 한 칸에만
   - 학년마다 스프레드시트를 따로: `SUBMIT_URLS`의 학년 칸에 각각
4. 워크시트가 `materials/g2-8/…`처럼 어느 학년 폴더에 있는지로 학년 탭이 정해집니다(주소 뒤에 `?tab=중2`가 붙어 전송).

주소가 비어 있으면 화면에서 채점만 되고 어디로도 전송되지 않습니다.

## 시뮬레이션 워크시트 만들기 (js/ws-kit.js)

`materials/is1-1/`~`is1-7/`(통합과학1 Ⅰ~Ⅲ단원), `materials/is2-1/`~`is2-6/`(통합과학2 Ⅰ~Ⅲ단원), `materials/se1-1/`~`se1-11/`(과학탐구실험1 Ⅰ~Ⅱ단원), `materials/se2-1/`~`se2-11/`(과학탐구실험2 Ⅰ~Ⅱ단원) 워크시트는 공통 키트로 채점합니다.

- 문항에 `data-key`와 정답(`data-answer`, 수는 `data-num`·`data-tol`)만 적으면 자동 채점되고,
  문항 묶음 `<div class="q" data-why="해설" data-hint="도움말">`의 해설이 피드백으로 나옵니다.
- 카드(`section.card`)마다 [확인하기] 버튼이 자동으로 붙어 그 카드만 바로 채점·피드백합니다.
- 서술형(`textarea.free`)은 점수 없이 핵심어(`data-keywords`)와 예시 답안(`data-model`)으로 피드백합니다.
- 시뮬레이션 안의 결과는 `WS.custom(key, { value, check, answer })`로 등록하면 함께 채점·제출됩니다.
- 제출은 `data-part="submit"` 카드의 [제출하고 채점받기]로 하며, 형식은 아화중 자료와 같은 폼 형식입니다.
