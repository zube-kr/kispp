# KISPP 과학실

프놈펜한국국제학교(Korean International School of Phnom Penh) 중학교 과학 수업 홈페이지입니다.
2022 개정 교육과정 중1~중3 과학과 고1 과목(통합과학1·2, 과학탐구실험1·2)을 기준으로 구성합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 메인 화면 (왼쪽 학년·단원 사이드바 + 홈/단원 화면) |
| `data/board.js` | 메인 화면 게시판 데이터: 과학실 공지(`NOTICES`), 쉬어가는 과학 게임(`GAMES`) |
| `data/units.js` | 학년·단원 목록과 단원 설명, 영역 색상, 단원별 학습 자료 목록(`materials`) |
| `materials/` | 단원별 학습 자료 페이지 (예: `materials/g2-6/` 중2 Ⅵ. 동물과 에너지) |
| `js/config.js` | 공통 설정. 활동지 답안을 받을 구글 Apps Script 주소(`SUBMIT_URL`) |
| `apps-script/code.gs` | 활동지 답안을 구글 스프레드시트에 저장하는 Apps Script (설치 방법은 파일 맨 위 설명) |
| `js/part-view.js` | 활동지 구간 보기 (`?part=concept` 등으로 열면 그 구간만 표시) |
| `layouts/` | 레이아웃 후보 샘플 (A~E)과 단원 화면 샘플(`layouts/unit-views/`), 참고용 |

## 주소 규칙

- `index.html#/g2` → 중학교 2학년 홈
- `index.html#/g2/3` → 중학교 2학년 3단원
- 고1 과목: `is1` 통합과학1, `is2` 통합과학2, `se1` 과학탐구실험1, `se2` 과학탐구실험2
  (예: `index.html#/is1/5` → 통합과학1의 5번째 단원 "지구시스템")

## 단원 수정하기

단원 이름이나 설명은 `data/units.js`만 고치면 메인 화면과 샘플에 함께 반영됩니다.

## 메인 화면 게시판

| 게시판 | 내용 채우는 곳 | 전체 보기(＋) |
|---|---|---|
| 과학실 공지 | `data/board.js`의 `NOTICES`에 공지 추가 (`pin: true`면 맨 위 고정) | `#/notice` |
| 실험 보고서 | 자동: 탐구실험(`lab`) 구간이 있는 우리 워크시트를 올린 날짜(`added`) 최신순으로 | `#/reports` |
| 쉬어가는 과학 게임 | `data/board.js`의 `GAMES`에 게임 추가 | `#/games` |

## 학습 자료 추가하기

1. 자료 페이지를 `materials/g학년-단원/` 폴더에 넣습니다.
2. `data/units.js`에서 해당 단원의 `materials` 목록에 항목을 추가합니다.
   - 다른 사이트 자료는 `external: true`를 붙이면 새 탭에서 열립니다.
   - `parts`: 자료 안의 구간 목록. `{ p: "concept", t: "실험 개요" }`처럼 적으면
     단원 화면에 색깔 칩으로 나오고, 누르면 그 구간만 열립니다.
     구간 종류: `concept` 개념정리 · `lab` 탐구실험 · `sim` 시뮬레이션 · `quiz` 형성평가
   - `added`: 올린 날짜(`"2026-10-16"`). 탐구실험이 있는 워크시트는 메인 화면 '실험 보고서'에 자동으로 나옵니다.
3. 활동지 페이지에서 각 `<section class="card">`에 `data-part="concept"`처럼 구간을 표시하고,
   `<script src="../../js/part-view.js"></script>`를 넣습니다. (표시가 없으면 카드 제목 배지로 짐작합니다.)
   제출 때 함께 채점되는 칸이 있는 구간은 `data-part="concept quiz"`처럼 두 가지를 적어
   형성평가만 열어도 제출할 수 있게 합니다.

## 단원 화면 구성

- 목록: 소단원 워크시트. 제목을 누르면 전체, 색깔 칩을 누르면 그 구간만(`?part=`) 열립니다.
- 위 네 버튼(개념정리·탐구실험·시뮬레이션·형성평가): 그 구간이 들어 있는 자료를 밝게 표시합니다.

## 활동지 답안 제출 연결하기

활동지는 학생이 제출하면 채점 결과를 구글 스프레드시트로 보냅니다.
`apps-script/code.gs`를 선생님 구글 시트에 설치하고, 발급된 웹 앱 주소를
`js/config.js`의 `SUBMIT_URL`에 넣으면 모든 활동지에 한 번에 적용됩니다.
주소가 비어 있으면 화면에서 채점만 되고 어디로도 전송되지 않습니다.

## 가져온 자료 출처

- 중2 Ⅵ. 동물과 에너지 활동지 2종: 아화중학교 과학 저장소(`zube-kr/science`)
- 중2 Ⅷ. 별과 우주 워크시트 6종: 경주여자중학교 3학년 Ⅶ. 별과 우주 학습지 목록(`zube-kr/gyeongju-girls-3rd`)
  - 이 워크시트들은 여러 구간의 답을 한 번에 제출하므로 `<body data-submit="full">`로 표시했고,
    구간 보기에서는 학생 정보·제출 구간을 숨기고 "제출은 전체 워크시트에서"라고 안내합니다.
  - 답안은 JSON 형식(`form` 값이 시트 이름)으로 보내며, `apps-script/code.gs`가 두 형식을 모두 받습니다.
