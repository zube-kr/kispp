아두이노 실험 보고서 · Ⅴ. 자극과 반응 · 교과서 146~148쪽 연계

빛을 보고, 소리를 듣고,
버튼을 누르기까지 몇 초?

LED가 켜지거나 버저가 울리면 최대한 빨리 버튼을 눌러 반응 시간을 1/1000 초 단위로 재 보자. 대뇌의 판단을 거치는 의식적 반응에 얼마나 걸리는지, 빛과 소리 자극에 차이가 있는지 확인해요.

실험 제목빛과 소리 자극에 대한 반응 시간 측정
관련 단원Ⅴ-2-02 신경계를 통해 일어나는 반응
실험 형태2인 1조
측정 도구아두이노 UNO + LED · 능동 부저 · 푸시 버튼
·실험 날짜와 실험자 이름
실험 목표 LED 빛과 버저 소리 자극을 받고 버튼을 누르는 의식적 반응의 시간을 1/1000 초 단위로 측정하여, 자극이 감각 기관 → 감각 신경 → 대뇌 → 운동 신경 → 근육을 거치는 데 걸리는 시간을 설명할 수 있다.
1가설 세우기
1빛을 보고 버튼을 누를 때와 소리를 듣고 버튼을 누를 때, 반응 시간은 얼마나 걸리고 어느 쪽이 더 빠를지 예상해 보자.
2반응의 종류 자극을 받고 버튼을 누르는 반응은 이다.
2준비물과 회로 연결

준비물 아두이노 UNO, USB 케이블, 브레드보드, LED, 220 Ω 저항, 능동 부저(액티브 부저), 푸시 버튼, 점퍼선, 노트북(크롬)

부품연결
LED(+220 Ω 저항)긴 다리 → 8번, 짧은 다리 → GND
능동 부저+ → 9번, − → GND
푸시 버튼한쪽 다리 → 2번, 대각선 다리 → GND (내부 풀업, 저항 필요 없음)

3실험 방법
  1. 측정할 사람은 LED와 버저를 볼 수 있게 앉고, 주로 쓰는 손 검지를 버튼 위에 살짝 올려놓는다.
  2. [아두이노 연결하기] 후 다른 사람이 [💡 빛 자극] 또는 [🔔 소리 자극]을 누른다. 1.5~4 초 뒤 자극이 나오면 최대한 빨리 버튼을 누른다.
  3. 빛, 소리 자극을 각각 10 번씩 측정한다(순서를 섞어서). 미리 누르면 반칙으로 기록하지 않는다.
  4. 역할을 바꾸어 반복한다. 아두이노가 없으면 [⌨️ 화면으로 해 보기]로 키보드 스페이스 키를 눌러 측정한다.
4측정하기
연결 안 됨크롬·엣지에서 연결돼요. 연결 없이도 화면으로 해 보거나 예시 값을 볼 수 있어요.

6결론과 토의
1결론 측정 결과를 바탕으로, 자극을 받고 버튼을 누르기까지 자극이 전달되는 경로와 시간이 걸리는 까닭을 설명해 보자.
2더 생각하기 빛과 소리의 평균 반응 시간에 차이가 있었다면 그 까닭은 무엇일까? 생활에서 이 결과를 어떻게 활용할 수 있을까?
3오차 분석 같은 사람이라도 측정할 때마다 반응 시간이 달라지는 까닭을 2 가지 써 보자.
