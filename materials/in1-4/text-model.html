텍스트 데이터를 이용한
영화 평가 시스템

같은 영화도 사람마다 감상평이 다르다. 교과서 감상평 120 개로 긍정·부정을 가르는 텍스트 분류 모델을 학습시키고, 틀린 문장을 보며 데이터를 보강한 뒤, 감상평 점수의 평균으로 영화를 평가하는 프로그램과 1~5점 평점 모델까지 만들어 보자.

🎯 학습 목표 — 텍스트 데이터를 분류하는 인공지능 모델을 생성하고, 텍스트 분류 모델을 활용하여 영화 평가 시스템을 구현할 수 있다.
1. 텍스트 데이터를 분류하는 인공지능텍스트 분류 모델 192쪽

텍스트 분류 모델은 텍스트 데이터를 학습하는 과정에서 텍스트의 패턴을 분석하여 특정 텍스트가 어떤 범주나 클래스에 해당하는지 분류하는 모델이다. 예를 들어 영화 댓글 평가 시스템에 긍정과 부정의 댓글 데이터를 충분히 학습시킨 텍스트 분류 모델을 이용하면 댓글의 전체적인 반응을 알 수 있다. 텍스트 분류 모델은 이메일 필터링 시스템에서 일반 메일과 스팸 메일을 구분하거나 SNS에서 부적절한 글을 찾아내는 데에도 활용할 수 있다.

이 페이지의 모델은 무엇을 읽을까? 문장을 낱말과 두 글자 조각(예: ‘최고’ → ‘ 최’, ‘최고’, ‘고 ’)으로 나누고, 긍정 문장과 부정 문장에 각 조각이 몇 번 나왔는지 세어 두었다가 새 문장이 어느 쪽과 더 닮았는지 확률로 계산해요(나이브 베이즈 방법).

문제 정의 영화 감상평의 긍정·부정을 분류하여 점수를 산출한 후 영화를 평가하는 프로그램 만들기. 긍정적인 평가와 부정적인 평가에 해당하는 글을 수집하고 적절하지 않은 데이터는 삭제한 후 레이블링한다. 텍스트 데이터는 쉼표(,)로 구분한다.

➊ 입력받은 값이 1이 될 때까지 영화 감상평을 입력받아 긍정인지 부정인지 분류한다. ➋ 분류 결과가 긍정이면 ‘점수’ 변수에 1을 더하고, 부정이면 ‘점수’ 변수에 −1을 더한다. ➌ 평균에 따라 감상평이 좋은 영화, 보통인 영화, 좋지 않은 영화로 알려 준다.

점수를 입력 개수로 나누는 이유 점수 범위를 −1.0 ~ 1.0으로 분포시킨 후 0.5 ~ 1.0은 평가가 좋은 영화, −0.5 ~ 0.5는 평가가 보통인 영화, −1.0 ~ −0.5는 평가가 좋지 않은 영화로 구분하기 위해서이다.
